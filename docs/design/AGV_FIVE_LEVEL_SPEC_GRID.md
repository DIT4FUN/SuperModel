## 关键API (GymAGVSpec)

```python
from src.simulation.gym_env import GymAGVSpec, get_gym_agv_spec, get_agv_control_params

# 获取类型安全的规格对象
spec = get_gym_agv_spec('M')
print(spec.control_freq_hz)    # 100.0
print(spec.payload_kg)         # 100.0

# 获取控制参数
ctrl = get_agv_control_params('L')
print(ctrl['dt'])              # 0.005
print(ctrl['collision_response_ms'])  # 20.0

# 获取传感器参数
sensor = spec.get_sensor_params()
print(sensor['imu_type'])      # BMI088
```
