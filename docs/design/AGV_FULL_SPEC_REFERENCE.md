## 十、模块接口速查

### 传感器统一接口

```python
from sensors.manager import SensorManager, SensorGrade

manager = SensorManager(grade=SensorGrade.M)  # M级配置
manager.start()
frame = manager.get_frame()  # 统一多模态帧
manager.shutdown()
```

### 融合统一接口

```python
from fusion.cross_modal_fusion import CrossModalFusion, FusionConfig, MultimodalInput

config = FusionConfig(vision_dim=512, audio_dim=128, hidden_dim=256)
fusion = CrossModalFusion(config)
output = fusion(MultimodalInput(vision=v, audio=a, tactile=t, force=f, imu=i))
```

### AGV控制统一接口

```python
from control.agv import AGVController, AGVGrade, DriveType

agv = AGVController(grade=AGVGrade.M, drive_type=DriveType.OMNIDIRECTIONAL)
spec = agv.spec  # AGVSpec
cmd = agv.compute_velocity(trajectory, current_pose)
```

### 安全控制器统一接口

```python
from control.safety_controller import SafetyController, SafetyLevel

safety = SafetyController(level=SafetyLevel.L)
safety.check_joint_limits(joint_positions)
safety.check_velocity_limits(velocities)
```

### 仿真环境统一接口

```python
from simulation.gym_env import SuperModelGymEnv, GymEnvConfig

env = SuperModelGymEnv(GymEnvConfig(grade="M"))
obs, info = env.reset()
obs, r, term, trunc, info = env.step(action)
env.close()
```
