## AGV传感器配置

```
传感器配置:

│   └── 位置: 车体中心
│   └── 功能: 姿态估计、惯性导航
│
├── 从动轮: ESUN 2.5寸 × 2
│   └── 位置: 车体前后底部
│   └── 功能: 支撑、减震、360°转向
│
└── 深度相机: RGB-D × 1 (可选)
    └── 位置: 车体前部
    └── 功能: 目标识别、视觉导航
```

## 硬件接口

### 传感器接口定义

```
传感器接口 (M8 6P防水连接器):
┌─────────────────────────────┐
│  1: VCC (9-36V)           │
│  2: GND                   │
│  3: CAN_H / RS485_A       │
│  4: CAN_L / RS485_B       │
│  5: Signal (可选)          │
│  6: Shield (屏蔽)          │
└─────────────────────────────┘

激光雷达接口 (RJ45 / 串口):
┌─────────────────────────────┐
│  TX: 串口发送              │
│  RX: 串口接收              │
│  VCC: 12V供电             │
│  GND: 地                   │
└─────────────────────────────┘
```

## 软件支持

### ROS/ROS2驱动

```bash
# 激光雷达驱动
sudo apt install ros-${ROS_DISTRO}-lslidar-n10p-driver

# IMU驱动
sudo apt install ros-${ROS_DISTRO}-imu drivers
```
